# Lily Math v10.14.0

November 11, 2026.

- Integrates the local Walter v11 prototype's work area and revisit loop into the current 10.13.0 app for all ten authored Unit 5 lessons. Unit 5 Lesson 11 keeps its existing mapped review route.
- Adds a Work it out panel beside guided, repair, independent and check-in problems. Pencil marks and typed notes save with the current problem and return after Pause & Home or reload.
- Adds Fill squares: tap to shade/clear; drag to paint or erase multiple squares; arrows and Space work from the keyboard. Undo treats a drag as one action and can restore a cleared page until that page is left. Each problem has its own blank scratch page.
- Preserves 10.13.0's fraction blocks and drawing-aware coaching. Generic scratch shading and freehand marks are working tools, with no automatic answer, help or correctness credit.
- Offers a direct Show a model choice in More help. Different-number models preserve the child's draft and count as support, including on a check-in. Opening the help menu alone does not count.
- Schedules the first Unit 5 review for the next calendar day at the difficulty actually practiced. A helped or missed review schedules another next-day opportunity; clean reviews retain the existing spaced intervals. Next practice difficulty remains separate.
- Recovers the practiced difficulty of older pending Unit 5 reviews from completed-session lesson records when available. Existing drafts, checked values, class choices and learner profiles remain compatible.
- Adds Unit 5 lesson/resume/check-in choices under Home → Browse all math, alongside the existing recommendation and class routes.

Qwen ran locally with fictional classroom cases. Reproduced reload, draft, scratch-credit, undo and difficulty scenarios were checked independently; invented block-drag controls and its claim that watching a model changes practiced difficulty were rejected. The initial direct-model exception was fixed during browser testing. The local v11 prototypes and the 10.13.0 artifact are preserved.
