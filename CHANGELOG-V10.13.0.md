# Lily Math v10.13.0

November 11, 2026.

- Extends Walter's diagram-aware feedback beyond Unit 5 to decimal blocks/charts, number-line landings, hundredths division grids, coordinate/data graphs, factor trees, area-model work, division chips, expression tiles and grouping controls.
- Shows attempted decimal blocks, graph points, jumps, factor branches and area-cell values before acceptance, clearly labelled as unchecked. Decimal blocks can be built with +/− controls as well as typed counts.
- Uses the learner's current representation for the next action: which place is missing, which side of an exchange stayed unchanged, whether a jump goes the wrong way, which coordinate needs work, or which grid group/cell is being checked. Existing specific authored clues and accepted work are preserved.
- Keeps tapped and typed graph points synchronized. Grid taps no longer overwrite axis-interval questions. Proposed points have a matching screen-reader description.
- Re-reads revised work when Still stuck is used instead of staying on an old smaller-model clue. Repeated delivery is deduplicated; edits alone are not help or mistakes.
- Saves bounded diagram observations in lesson and homework evidence. Helped completion stays supported, with existing fresh-check behavior and resume support.
- Retains the Unit 5 fraction-block behavior, including equivalent arrangements, unfinished drawing review and separate math/error evidence.
- Clearly states that Walter cannot read freehand scratch-paper marks. Read-only illustrations are not treated as drawings made by Lily.

Local Qwen was used for fictional beginner attacks. Its invented controls and incorrect decimal calculations were rejected; independently checked scenarios and actual browser interactions determined the fixes. Previous releases and local v11 prototypes are preserved. No progress-data reset or schema migration.
