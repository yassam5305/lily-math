# v10.24.0 · Adaptive decimal warm-ups

New warm-ups have eight questions. A familiar opening and a place-value question lead into decimal practice, a related topic and a return to the original skill. Walter picks the difficulty for each application using that player’s recent work on the same skill.

Two distinct first-try answers at the same difficulty can lead to a stretch. Two different problems needing retries can lead to a smaller step. Asking for a clue or a drawing keeps help available. An application that displays a checked fact does not count toward a stretch. There is no timer or grade.

Parents can see the difficulty practiced, the support used and what Walter would offer next for the most recently practiced application. Existing three-question drafts can still be finished. Enrollment and regular lessons stay profile-specific.

After two unsuccessful checks, a learner can set the problem aside and continue. Walter records that choice separately from a correct answer. He recognizes equivalent fractions and invites the learner to write the decimal. An unfinished decimal point can be edited without counting a miss. Place charts include a tens column when a given needs one.
