# v10.21.0 · Classroom fraction grids

November 18, 2026

Unit 5’s fraction-addition area lessons now open with two equal rectangles. The first rectangle shows the first addend in shaded rows. The second shows the second addend in shaded columns. Both rectangles have the same grid, so a learner can count pieces of the same size before adding. The Drawing menu also offers fraction strips.

For 1/2 + 3/8, the classroom grid uses two rows and eight columns. The completed drawing shows 8/16 + 6/16 = 14/16 = 7/8. The completed strips show 4/8 + 3/8 = 7/8. During practice the learner chooses a common denominator and enters each count. Switching the drawing keeps the current entry and checked steps. Word problems offer the drawings after the learner checks the expression.

The representations also appear in matching area-model addition homework within the drawing limits of 120 cells and six wholes per addend. The update contains no homework photos or student work.
